# Changelog - v0.2.0

## Release Summary
Version 0.2.0 introduces the **Mock VNeID Identity Provider & National Medical Registry Service** (`apps/mock-vneid`), built with Node.js and Express following the architecture of `@opengovsg/mockpass`.

---

## New Features & Enhancements

### 1. Mock VNeID OIDC & OAuth 2.0 Identity Provider (`apps/mock-vneid`)
- **Interactive VNeID Browser Login (`GET /oauth/authorize`)**:
  - Implements authentic visual branding from Vietnam Ministry of Public Security (BCA) based on `new.html`.
  - Features split layout: direct CCCD & password credential form on the left, interactive QR code scanner with simulated mobile app scan on the right.
  - Includes a top developer toolbar for 1-click persona testing (preloaded doctors, standard citizens, edge cases).
  - Emits a standard HTTP 302 GET redirect back to the BFF callback with `?code=AUTH_CODE&state=STATE`.
- **Back-Channel Token Exchange (`POST /oauth/token`)**:
  - Exchanges authorization codes for a complete JWT token set: `id_token`, `access_token`, and `refresh_token`.
  - Generates RS256 digital signatures using an ephemeral in-memory RSA 2048-bit keypair.
  - Automatically enriches token claims with demographic details (CCCD, BHYT) and practitioner credentials (`cchn`, `facility_id`, `roles`) for verified doctors.
- **Public JWKS Key Distribution (`GET /.well-known/jwks.json`)**:
  - Exposes the active RSA public key in standard JWKS format, allowing .NET Core WebApi and BFF to verify token signatures offline without introspect round-trips.
  - Provides OpenID configuration discovery at `GET /.well-known/openid-configuration`.

### 2. National Registries (C06 & BYT) Server-to-Server APIs
- **C06 Citizen Database (`GET /api/v1/c06/citizen/:cccd`)**:
  - Simulates the National Population Database (C06) to retrieve full demographic profiles, permanent address, phone, and health insurance card numbers with discount rates.
- **BYT Medical Practitioner Registry (`GET /api/v1/byt/practitioner/:cchn`)**:
  - Simulates the Ministry of Health (BYT) licensing registry to verify physician practice certificate numbers (CCHN), clinical scope, active status, and affiliated hospital code (`ma_cskcb_cong_tac`).
- **BYT Healthcare Facilities Directory (`GET /api/v1/byt/facilities`)**:
  - Returns registered hospital profiles with administrative codes, hospital tier, classification (`ĐB`, `1`, `2`), and address.

### 3. Isolated Mock Data Storage
Separated into three independent JSON datasets in `apps/mock-vneid/data/`:
- `citizens.json`: Demographic and BHYT insurance records.
- `medical_facilities.json`: Official healthcare facility directory.
- `medical_practitioners.json`: Physician practice licenses and hospital affiliations.

### 4. Infrastructure & Containerization
- Created standalone `Dockerfile` for `apps/mock-vneid` using `node:20-alpine`.
- Added `vneid-mock` service in root `docker-compose.yml` mapped to port `5001`.
- Configured environment variables in `.env.example`.
