# Changelog - Version 0.1.0

Release Date: November 2026

## Initial Setup & Architecture Scaffolding

### Monorepo Structure
- Initialized repository architecture with dedicated applications inside `apps/` directory:
  - `apps/worker`: Python FastAPI 3D UNet inference service.
  - `apps/backend`: .NET 8 WebApi with Clean Architecture.
  - `apps/web`: Next.js 14 App Router frontend.
- Configured root `.gitignore` covering Python, .NET, Node, and environment files.
- Provided Docker Compose configuration using stable `postgres:16-alpine` and `dpage/pgadmin4`.
- Configured synchronized `.env` and `.env.example` templates across all services.

### Python AI Worker (`apps/worker`)
- Extracted and ported 3D Residual U-Net architecture from baseline notebook.
- Implemented test-time Monte Carlo Dropout ($T=20$) for Bayesian uncertainty estimation.
- Added volumetric percentile curve computation ($1$ to $99$) for WT, TC, and ET in $\text{cm}^3$.
- Generated multi-label spatial quantile masks at $p=5\%$, $p=50\%$, and $p=95\%$ saved into `apps/worker/temp/`.
- Implemented OLS linear regression calibration matching theoretical uniform quantiles ($u_k \approx a \cdot (\alpha_{(k)} - 0.5) + 0.5$).
- Built internal 3-Fold Cross-Validation calibration pipeline across 34 validation cases (`val_calibration/`).
- Added `GET /api/mask/{task_id}?p={percentile}` endpoint for on-demand NIfTI mask retrieval.
- Provided `scripts/calibrate_val.py` CLI and `calibration_cache.json` persistence.
- Built non-blocking `colab_runner.ipynb` for automated Google Colab deployment and Cloudflare Tunnel exposure.

### .NET Backend API (`apps/backend`)
- Implemented Clean Architecture layers: `NeuroScan.Domain`, `NeuroScan.Application`, `NeuroScan.Infrastructure`, and `NeuroScan.WebApi`.
- Designed domain models for `User`, `Hospital`, `Doctor`, and `RefreshToken`.
- Configured custom JWT authentication and role-based access control (`Admin`, `HospitalAdmin`, `Doctor`).
- Integrated Entity Framework Core with PostgreSQL provider (`Npgsql`).
- Configured resilient HTTP client `WorkerHttpClient` for worker communication.
- Automated database seeding for initial administrator account.

### Web Client (`apps/web`)
- Initialized Next.js 14 with TypeScript, App Router, and Tailwind CSS.
- Built responsive clinical dashboard with navigation sidebar and health indicators.
- Created management interfaces for hospitals and doctors with interactive modals.
- Built MRI segmentation interface with 4-sequence file upload, volumetric tables, and mask download.

### Documentation & Conventions
- Created `docs/README.md` containing agent onboarding guide and architectural blueprints.
- Established strict zero-comment source code policy across all codebase components.
